## சிந்திக்க / நினைவு கூர் வினாக்கள் (book p. 51)

1. ஒரு வட்டத்தின் சுற்றளவு $C = 2\pi r$ மற்றும் பரப்பளவு $A = \pi r^2$ ஆகியவற்றில் $\pi$ இன் மதிப்பு என்ன?
2. ஒரு வட்டத்தின் விட்டம் $d$ மற்றும் ஆரம் $r$ ஆகியவற்றிற்கு இடையே உள்ள தொடர்பு யாது?

## பயிற்சி 2.1 (book pp. 60-61)

1. கோடிட்ட இடங்களை நிரப்புக:
   (i) வட்டத்தின் பரிதிக்கும் அதன் விட்டத்திற்கும் இடையேயான விகிதம் ________.
   (ii) ஒரு வட்டத்தின் மீதுள்ள ஏதேனும் இரண்டு புள்ளிகளை இணைக்கும் கோடு ________.
   (iii) ஒரு வட்டத்தின் மிகப் பெரிய நாண் ________ ஆகும்.
   (iv) 24 செ.மீ. விட்ட அளவுள்ள ஒரு வட்டத்தின் ஆரம் ________.
   (v) வட்டப்பரிதியின் ஒரு பகுதியே ________ ஆகும்.

2. பின்வருவனவற்றைப் பொருத்துக:

| எண் | வினா | விடை |
| :---: | :--- | :--- |
| (i) | வட்டத்தின் பரப்பளவு | (அ) $\frac{1}{4}\pi r^2$ |
| (ii) | வட்டத்தின் சுற்றளவு | (ஆ) $(\pi + 2)r$ |
| (iii) | வட்டக்கோணப் பகுதியின் பரப்பளவு | (இ) $\pi r^2$ |
| (iv) | அரைவட்டத்தின் சுற்றளவு | (ஈ) $2\pi r$ |
| (v) | கால்வட்டத்தின் பரப்பளவு | (உ) $\frac{\theta^\circ}{360^\circ} \times \pi r^2$ |

3. நிழலிடப்பட்டுள்ள வட்டக்கோணப் பகுதிகளின் மையக்கோணங்களைக் காண்க (ஒவ்வொரு வட்டமும் சம அளவு வட்டக்கோணப் பகுதிகளாகப் பிரிக்கப்பட்டுள்ளது):
   (i) அரைவட்டம் ($n = 2$)
   (ii) கால்வட்டம் ($n = 4$)
   (iii) ஐந்தில் ஒரு பகுதி ($n = 5$)
   (iv) எட்டில் ஒரு பகுதி ($n = 8$)

4. கீழே கொடுக்கப்பட்டுள்ள அளவுகளைக் கொண்ட வட்டக்கோணப் பகுதிகளின் வில்லின் நீளம், பரப்பளவு மற்றும் சுற்றளவு ஆகியவற்றைக் காண்க ($\pi = 3.14$):
   (i) மையக்கோணம் $45^\circ, r = 16\text{ செ.மீ.}$
   (ii) மையக்கோணம் $120^\circ, d = 12.6\text{ செ.மீ.}$

5. கீழே கொடுக்கப்பட்டுள்ள அளவுகளைக் கொண்ட வட்டக்கோணப் பகுதிகளின் பரப்பளவு காண்க:
   (i) வட்ட வில்லின் நீளம் $= 48\text{ மீ}, r = 10\text{ மீ}$
   (ii) வட்ட வில்லின் நீளம் $= 50\text{ செ.மீ}, r = 13.5\text{ செ.மீ}$

6. கீழே கொடுக்கப்பட்டுள்ள அளவுகளைக் கொண்ட வட்டக்கோணப் பகுதிகளின் மையக்கோணம் காண்க ($\pi = \frac{22}{7}$):
   (i) பரப்பளவு $= 462\text{ செ.மீ}^2, r = 21\text{ செ.மீ}$
   (ii) வட்டவில்லின் நீளம் $= 44\text{ மீ}, r = 35\text{ மீ}$

7. $120\text{ மீ}$ ஆரமுள்ள வட்டமானது 8 சம அளவுள்ள வட்டக்கோணப் பகுதிகளாகப் பிரிக்கப்படுகிறது. அவை ஒவ்வொன்றின் வில்லின் நீளத்தையும் காண்க.

8. $70\text{ செ.மீ}$ ஆரமுள்ள வட்டமானது 5 சம அளவுள்ள வட்டக்கோணப் பகுதிகளாகப் பிரிக்கப்படுகிறது. அவை ஒவ்வொன்றின் பரப்பளவைக் காண்க.

9. தாமு தனது வீட்டின் தரைப்பகுதியில் $30\text{ செ.மீ}$ பக்க அளவுள்ள சதுரவடிவ ஓட்டினைப் பதித்துள்ளார். அதன் மீது வட்டக்கோண வடிவில் கோலமிடுகிறார் எனில், அக்கோலத்தின் பரப்பளவைக் காண்க ($\pi = 3.14$).

10. மையக் கோணம் $45^\circ$ மற்றும் ஆரம் $56\text{ செ.மீ}$ உடைய 8 சம அளவுள்ள வட்டக்கோண வடிவ கிரானைட் கற்களைக் கொண்டு ஒரு வட்ட வடிவம் உருவாக்கப்படுகிறது எனில், அவை ஒவ்வொன்றின் பரப்பளவைக் காண்க ($\pi = \frac{22}{7}$).

## பயிற்சி 2.2 (book pp. 67-68)

1. கீழே கொடுக்கப்பட்டுள்ள கூட்டு வடிவங்களின் சுற்றளவு மற்றும் பரப்பளவு காண்க ($\pi = \frac{22}{7}$):
   (i) ஒரு செவ்வகத்தின் மீது அரைவட்டம் இணைக்கப்பட்ட வடிவம் (நீளம் $10\text{ மீ}$, அகலம் $7\text{ மீ}$).
   (ii) ஒரு செவ்வகத்தின் இரு முனைகளிலும் கால்வட்டங்கள் வெட்டி எடுக்கப்பட்ட வடிவம் (நீளம் $6\text{ செ.மீ}$, அகலம் $3.5\text{ செ.மீ}$).

2. பின்வரும் படங்களில் நிழலிடப்பட்டுள்ள பகுதியின் பரப்பளவைக் காண்க ($\pi = 3.14$):
   (i) $10\text{ செ.மீ}$ பக்க அளவுள்ள சதுரத்தின் நடுவே நான்கு கால்வட்டங்களால் சூழப்பட்ட நிழலிட்ட பகுதி.
   (ii) $7\text{ செ.மீ}$ பக்க அளவுள்ள சதுரத்தின் உள்ளே அமைந்த நிழலிட்ட பகுதி.

3. படத்தில் கொடுக்கப்பட்டுள்ளவாறு, இரண்டு இணைகரங்களை ஒன்றாக இணைத்து உருவாக்கப்பட்ட கூட்டு வடிவத்தின் பரப்பளவைக் காண்க.

4. $6\text{ செ.மீ}$ விட்டமுள்ள அரைவட்டத்தையும், அடிப்பக்கம் $6\text{ செ.மீ}$ மற்றும் உயரம் $9\text{ செ.மீ}$ அளவுள்ள முக்கோணத்தையும் இணைத்து உருவாக்கப்பட்ட வடிவத்தின் பரப்பளவைக் காண்க.

5. அறுங்கோண வடிவில் உள்ள ஒரு கால் மிதியடியானது படத்தில் உள்ளவாறு அளவுகளைக் கொண்டுள்ளது. அதன் பரப்பளவைக் காண்க.

6. ஓர் ஏவுகணையின் படமானது, படத்தில் கொடுக்கப்பட்டுள்ளவாறு அளவுகளைக் கொண்டுள்ளது. அதன் பரப்பளவைக் காண்க.

7. கீழே கொடுக்கப்பட்டுள்ள ஒழுங்கற்ற பலகோண வடிவ நிலங்களின் பரப்பளவைக் காண்க.

## இவற்றை முயல்க - ஆய்லர் சூத்திரம் (book p. 70)

பின்வரும் பன்முக வடிவங்களின் முகங்கள் ($F$), உச்சிகள் ($V$) மற்றும் விளிம்புகளின் ($E$) எண்ணிக்கையை அட்டவணைப்படுத்துக மற்றும் ஆய்லர் சூத்திரத்தை ($F + V - E = 2$) சரிபார்க்க:

| திண்மம் பெயர் | முகங்கள் ($F$) | உச்சிகள் ($V$) | விளிம்புகள் ($E$) | $F + V - E$ |
| :--- | :---: | :---: | :---: | :---: |
| கனச்சதுரம் | 6 | 8 | 12 | 2 |
| கனச்செவ்வகம் | | | | |
| முக்கோணப் பட்டகம் | | | | |
| சதுரப் பிரமிடு | | | | |
| முக்கோணப் பிரமிடு | | | | |

## பயிற்சி 2.3 (book p. 73)
