## Extraction Flags

- **Excluded non-evaluation content:** Recap bullets, the Glossary table, Reference Books, Internet Resources, and the running page footers on printed pages 32 to 34. The Bardoli Satyagraha photograph caption is not an evaluation item.
- **Match-the-following verification (Section III):** Each printed pairing was checked against the chapter text.
  - Permanent Settlement is printed with Madras. The Page 32 print image text says the permanent settlement was made in Bengal, Bihar, Orissa and the Varanasi division, and the Recap on the same page says Lord Cornwallis introduced it in 1793. This pair is contradicted.
  - Mahalwari Settlement is printed with Misery of the Indigo cultivators. The Page 34 print image text describes the Mahalwari settlement (Robert Martins Bird, 1833; Lambardars as intermediaries) and the Page 35 print image places the indigo misery under a separate Indigo Revolt (1859-60) heading. This pair is contradicted.
  - Ryotwari System is printed with North west province. The Page 33 print image text says it was introduced by Thomas Munro and Captain Read in 1820 and does not mention the North west province. This pair is not supported, but it is not directly contradicted.
  - Nil Darban is printed with Bengal, which agrees with the Dinabandhu Mitra Nil-Darpan (Bengali drama) entry on the Page 38 print image. This pair is consistent.
  - Santhal Rebellion is printed with First Peasant revolt. The chapter text on the Page 34 and Page 35 print images describes the Santhal cultivation near Rajmahal and a Santhal Rebellion heading, but does not state that it was the first peasant revolt. This pair is not supported.
  - Two rows are concretely contradicted (Permanent Settlement and Mahalwari Settlement), so the table is treated as scrambled and rendered as two unpaired lists with pairing not asserted.
